 🧠 Quizz Pro – Android Quiz App

An interactive Quiz Android Application built using Kotlin as part of my internship at HexSoftwares.
🚀 Features

* 📚 Multiple Quiz Categories (History, Science, Sports, Music)
* ⏱️ Timer-based questions
* ❤️ Lives system
* 🎯 Score tracking
* 🏆 Leaderboard (Top Brains)
* 📊 Result screen with performance stats
* 🔄 Play again & navigation system
